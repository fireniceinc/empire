Seed Agent Overview

The PrimeForge Seed Agent is the canonical reference implementation demonstrating CPL → CPO → Cartridge orchestration. It proves deterministic multi‑agent behavior under constitutional governance.

Seed Agent Responsibilities

  • Executes CPL-defined processes deterministically
  • Interacts with CPO kernel identity and autonomy modes
  • Demonstrates cartridge-safe memory operations
  • Provides reproducible agent workflows
  • Validates constitutional constraints
  • Serves as the baseline for all PrimeForge agents

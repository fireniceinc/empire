CPO Kernel Specification

The CPO (Constitutional Process Orchestrator) kernel is the sovereign substrate of PrimeForge. It enforces identity, autonomy modes, cartridge isolation, deterministic scheduling, and constitutional governance.

Core Kernel Responsibilities

  • Identity anchoring and verification
  • Deterministic scheduling of CPL processes
  • Cartridge isolation and memory governance
  • Autonomy mode enforcement
  • Constitutional rule execution
  • Agent messaging and workflow routing
  • Privacy mode constraints
